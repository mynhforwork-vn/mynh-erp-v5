# MYNH ERP V5 — Design Freeze Option 1

## Nhận diện
- Phong cách: Dense Rounded Enterprise — hiện đại, chuyên nghiệp, mật độ cao.
- Font duy nhất: Inter (400/500/600/700).
- Màu thương hiệu chính: `#22324A`.
- Màu thương hiệu phụ: `#365072`.
- Nền ứng dụng: `#F5F7FA`.
- Card / panel: `#FFFFFF`.
- Viền: `#E5EAF1`, viền nhấn `#D6DEE8`.
- Chữ chính: `#17212F`; chữ phụ `#5B6778`; chữ mờ `#8A94A6`.

## Màu trạng thái
- Thành công: nền `#EAF7EF`, chữ `#1F7A45`.
- Cảnh báo: nền `#FFF4E5`, chữ `#B26A00`.
- Lỗi: nền `#FDECEC`, chữ `#C73A3A`.
- Thông tin: nền `#EEF4FB`, chữ `#315D8A`.
- Trung tính: nền `#F1F3F5`, chữ `#6B7280`.

## Ngôn ngữ
- Giao diện người dùng dùng tiếng Việt toàn bộ.
- Mã kỹ thuật chỉ giữ ở backend; UI dùng nhãn tiếng Việt.

## Định dạng dữ liệu
- Ngày giờ: `DD/MM/YYYY HH:mm`.
- Ngày: `DD/MM/YYYY`.
- Giờ: `HH:mm`.
- SĐT: `0986 221 804`.
- Tiền: `658.000 đ`.

## Layout
- Sidebar 208–220px; nền navy.
- Panel chi tiết phải: 380–390px.
- Không popup cho nghiệp vụ chính.
- Table compact, sticky header, row 34px, font dữ liệu 11–12px.
- Card/panel radius 7–8px; input/button radius 6px.
